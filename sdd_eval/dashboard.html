执行协议

所有任务均使用 V2 数据契约。公开 Instance 与私有 Oracle 分离；模型提交 Prediction 后由独立 Worker 在 Local 或 Docker Backend 中执行，最终以目标测试和回归测试共同判定。

基准测试实例

FAIL_TO_PASS（目标测试）和 PASS_TO_PASS（回归测试）在导入数据集时写入私有评测标准。为避免泄露隐藏测试，页面仅展示最近一次执行的通过数/总数，不展示具体测试选择器。

从 GitHub / GitCode 补充测试用例

先按平台、编程语言和项目名称（模糊匹配）查找项目，再按 PR 代码变更行数筛选已合并 PR。导入后会创建带私有可执行 Oracle 的测试实例。
